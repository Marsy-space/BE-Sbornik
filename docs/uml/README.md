# UML Диаграммы

В данной папке хранятся исходники и изображения диаграмм проекта.

* **`UseCase-Sbornik-Retseptov.drawio`** — диаграмма вариантов использования. Описывает роли (Guest, User, Admin) и их действия в системе (просмотр, регистрация, редактирование рецептов, фильтрация по аллергенам).
* **ER-диаграмма** — схема базы данных (см. файл `docs/database.md`).

# Схема базы данных

В качестве СУБД используется **PostgreSQL**. Взаимодействие с базой данных происходит через ORM SQLAlchemy.

## Основные таблицы
1. **users** — хранит данные пользователей (email, password_hash, role_id).
2. **roles** — справочник ролей (Guest, User, Admin).
3. **recipes** — основные данные рецептов (название, описание, автор, приватность).
4. **recipe_ingredients** — связь рецептов и ингредиентов (Many-to-Many).
5. **ingredients** — справочник ингредиентов (название, единицы измерения).
6. **steps** — пошаговые инструкции приготовления.
7. **favorites** — избранные рецепты пользователей (с возможностью хранения личных заметок).
8. **reviews** — отзывы и рейтинги к рецептам.
9. **recipe_history** — история изменений рецептов (позволяет откатывать старые версии).

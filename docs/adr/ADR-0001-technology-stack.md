# ADR-0001: Выбор технологического стека

**Дата:** 01.10.2026
**Статус:** Принято
**Контекст:** Нам нужен стек для разработки бэкенда, который будет быстро работать, легко разворачиваться и поддерживаться командой из 4 человек.

## Решение
Мы выбрали следующий стек:
* **Язык:** Python 3.11
* **Фреймворк:** FastAPI
* **ORM:** SQLAlchemy
* **БД:** PostgreSQL
* **Аутентификация:** JWT (JSON Web Tokens)
* **Контейнеризация:** Docker / Docker Compose

## Обоснование и альтернативы
1. **FastAPI vs Django/Flask:**
   * Django слишком тяжелый и содержит много встроенного функционала, который нам не нужен.
   * Flask требует ручной настройки валидации и документации.
   * **FastAPI** выбран за асинхронность, встроенную валидацию Pydantic и автогенерацию Swagger-документации, что экономит время на написание ТЗ для фронтенда.
2. **PostgreSQL vs SQLite/MySQL:**
   * SQLite не подходит для продакшена и конкурентной записи.
   * PostgreSQL выбран за надежность, поддержку строгих типов данных и бесплатность (Open Source).
3. **SQLAlchemy:**
   * Позволяет работать с БД через Python-классы, что ускоряет разработку и снижает риск SQL-инъекций.

## Последствия
* Команде нужно изучить Pydantic и асинхронность (в рамках study-задач).
* Swagger UI генерируется автоматически, что упрощает тестирование.
